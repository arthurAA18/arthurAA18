## `01 // Sobre mim`

Olá! Sou **Arthur Andrade de Aguiar**, estudante de Sistemas de Informação e entusiasta da tecnologia.

Tenho interesse especialmente em **Suporte de TI, Infraestrutura, Redes de Computadores e Segurança da Informação**.
